# Sri Sri Kedarnath Mandir – Sri Sri Bhaktivedanta Ashram

Premium black-and-gold responsive website for the temple at Makrampur, Bolpur, West Bengal.

## Pages / sections
- Home
- About the Temple
- Maharaj – Paramananda Giri Maharaj
- Darshan & Puja, including the daily aarti schedule
- Festivals & Events – Damodara Deepdaan Utsav
- Gallery
- Seva & Donation with the QR code decoded from the temple's supplied notice
- Contact & Google Maps

## Features
- Responsive layout for desktop, tablet and mobile
- Black-and-gold visual theme with larger typography
- English / Bengali language toggle
- Mobile navigation menu
- Click-to-enlarge gallery
- Tap-to-call phone links
- Google Maps address search and directions
- UPI payment link and QR code
- No build tools or installation required

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Optional local server: run `python -m http.server 8000` from this folder, then visit `http://localhost:8000`.

## Daily aarti schedule transcribed from the temple notice
- Shri Mangal Aarti: 4:00 AM–5:10 AM
- Shri Shringar Aarti: 9:15 AM–9:30 AM
- Bhog Aarti: 1:00 PM
- Jagaran Aarti: 4:30 PM
- Shri Sandhya Aarti: 6:30 PM–7:40 PM
- Shri Krishna Katha: 8:00 PM
- Prasad enquiry: call between 9:00 AM and 10:00 AM

The notice does not give separate public darshan opening hours. Visitors should call the temple to confirm darshan availability before travelling. During the Damodara Deepdaan Utsav period, the festival poster announces evening aarti from 6:15 PM; confirm the day's timing with the temple.

## Damodara Deepdaan Utsav
- Poster dates: 22 October–24 November 2026
- Programme: Sri Sri Damodarashtakam Kirtan and Deepdaan daily after Sandhya Aarti
- Poster-listed seva amounts:
