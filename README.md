# Sri-Sri-Kedarnath-Mandir
A premium, responsive temple website for Sri Sri Kedarnath Mandir &amp; Sri Sri Bhaktivedanta Ashram, Makrampur, Bolpur, West Bengal. Features temple information, Maharaj biography, Darshan &amp; Puja timings, daily Aarti, festivals, photo gallery, Seva &amp; Donations, QR code and Google Maps integration.
